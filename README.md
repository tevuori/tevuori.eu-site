# tevuori.eu

Personal developer portfolio site for **Jakub Horák** (Tevuori).

## Stack
- Plain HTML / CSS / Vanilla JS
- Google Fonts (Inter + JetBrains Mono)
- No frameworks, no build step

## Profile photo
Place your photo at `assets/avatar.jpg`. If not present, initials fallback `JH` is shown automatically.

## Structure
```
index.html       — main page
style.css        — design system + layout
style-reveal.css — scroll reveal animations
app.js           — typing effect + scroll reveal
assets/          — static assets (avatar.jpg, …)
```
